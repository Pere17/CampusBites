# Adding photos

Drop image files directly into `vendors/` or `menu/` using the exact filename
listed below (any of `.jpg`, `.jpeg`, `.png`, `.webp` works — the page tries
each extension automatically). You don't need to add all of them at once —
any vendor or dish without a photo just shows a neat icon placeholder instead,
nothing breaks.

Run `node data/list-images-needed.js` any time to regenerate this list after
adding vendors or menu items.

**Recommended:** landscape photos, roughly 4:3 (e.g. 800×600px), under ~300KB each.
